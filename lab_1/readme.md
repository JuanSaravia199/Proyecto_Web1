# Laboratorio 2: Diseño Responsivo

En este laboratorio se transformó la landing page para que sea completamente responsiva aplicando la estrategia **Mobile-First**. 

- Se utilizó **CSS Grid** (`grid-template-areas`) para el layout principal.
- Se definieron breakpoints para Tablet (`768px`) y Escritorio (`1024px`).
- Se integró el framework **Bootstrap 5** exclusivamente en la sección de Contacto para estilizar el formulario de manera rápida y eficiente, sin afectar el Grid general.
